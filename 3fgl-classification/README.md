# Классификация астрофизических источников (3FGL)

Бинарная классификация блазаров и пульсаров по данным каталога Fermi LAT (3FGL).

## Данные
- 3034 объекта, 28 числовых признаков (параметры спектра).
- Целевая переменная: блазар (1) vs пульсар (-1).
- Дисбаланс классов: 1717 блазаров против 167 пульсаров.

## Методы
- **EDA**: матрица ковариаций, PCA для снижения размерности.
- **Модель**: DecisionTreeClassifier (max_depth=4).
- **Борьба с дисбалансом**: oversampling миноритарного класса.
- **Отбор признаков**: feature importance.

## Результаты
| Метрика | Значение |
|---|---|
| Accuracy | 0.97 |
| Precision (пульсары) | 0.88 |
| Recall (пульсары) | 0.80 |

Ключевые признаки: Par9, Par26, Par10.

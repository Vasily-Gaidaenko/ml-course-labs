# ML Course Labs

Коллекция лабораторных работ и проектов по машинному обучению.

## Проекты

### 1. Классификация астрофизических источников (3FGL)
Бинарная классификация блазаров и пульсаров по данным каталога Fermi LAT.
- **Методы**: EDA, PCA, DecisionTree, борьба с дисбалансом классов.
- **Результат**: accuracy 97%, precision 0.88, recall 0.80.

### 2. Устойчивость CNN к сдвигу изображений (MNIST)
Исследование того, как разные архитектуры CNN справляются со сдвигом входных изображений.
- **Методы**: ручная аугментация (сдвиг через numpy), сравнение 3 архитектур.
- **Результат**: улучшенная сеть (AveragePooling, Adam) устойчивее к сдвигу, чем базовая с аугментацией.

- ## Стек
Python, numpy, pandas, scikit-learn, Keras/TensorFlow, matplotlib, seaborn.
